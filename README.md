# Tactix Pro - Football Tactical Lineup & Formation Strategy Management System

An interactive, responsive football (soccer) tactical board and squad management frontend application.

## ⚽ Features
- **Interactive Green Football Pitch**: Realistic mown turf stripes, penalty boxes, center circle, penalty arcs, goal areas, and goalposts with nets.
- **Formation Preset Selector**:
  - `4-3-3 Attacking`
  - `4-4-2 Classic`
  - `3-5-2 Midfield Control`
  - `4-2-3-1 Defensive`
  - `5-3-2 Solid Block`
  - `3-4-3 High Press`
- **Draggable & Clickable Player Tokens**:
  - Drag players freely to any position across the pitch.
  - Click players to edit Name, Jersey Number, Pitch Position (`GK`, `CB`, `LB`, `RB`, `CM`, `LW`, `RW`, `ST`), Tactical Role, and Team Captaincy (`©`).
- **Substitutes Bench Roster**:
  - Reserve players management.
  - Instant substitution swapping (`Sub ⇄`) between bench players and starting players.
  - Add new reserve players directly from the bench panel.
- **Team Customization & Tactics**:
  - Dynamic jersey color pickers for Outfield and Goalkeeper kits.
  - Team Mentality controls (Defend / Balanced / Attack) with defensive line height adjustments.
  - Export tactical lineup report for printing or saving as PDF.

## 🛠️ Built With
- **HTML5** (Semantic Markup)
- **CSS3** (Modern Glassmorphism, Dark UI, Responsive Design)
- **Vanilla JavaScript** (Pointer Events, Clean DOM Manipulation)
